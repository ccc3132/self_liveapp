# 8. 아직 확인하지 못한 것

> [메인 README](../../README.md) · 이전: [7. 로드맵](07_roadmap_readme.md) · 다음: [9. 겪었던 문제 모음](09_issues_readme.md)

자동 테스트와 브라우저 점검 범위 밖입니다.

- 직원 수정·삭제·비밀번호 변경 화면, 권한 수정·삭제 버튼의 실제 동작(요청 형식과 등록만 테스트로 확인 — 기존 통합 테스트가 DB 수준까지 검증함)
- 기업회원(`ENTERPRISE`) 로그인, 아이디·비밀번호 찾기, 5회 실패 시 계정 잠금, 동시 세션 제한(1개)
- 메일 발송의 실제 전송 성공 경로(Mailpit 로 확인했으나 진짜 외부 SMTP 서버로는 확인하지 않음). SMTP 미설정/무응답 시 실패 처리(20초 타임아웃)는 확인함
- 권한을 바꾼 사용자의 세션 반영 시점
- `prod` 프로필(외부 PostgreSQL)로 실행, 외부 Tomcat 배포
- Linux 에서 내장 PostgreSQL 실행(Windows 에서만 확인), `run.bat` 더블클릭 실행
- 공식 호환성 확인 도구 검사(규칙은 가이드 문구를 코드로 옮긴 것)
- Docker 빌드·배포 전반(이 PC에 Docker 미설치 — [10. 외부 서버에 배포하기](10_deploy_readme.md) 참고)
- 쪽지 수신자 검색 팝업이 정상적으로 열렸을 때의 전체 흐름(자동화 도구가 브라우저 팝업 차단에 걸려 완전히 재현하지 못함 — 차단 시 크래시 나던 건 고쳤음)
- 각 등록 폼의 파일 첨부 업로드 자체(폼이 뜨는 것과 저장 자체는 확인, 실제 파일 업로드는 자동화하지 못함)
