# 1. 현재 상태 한눈에

> [메인 README](../../README.md) · 이전: [0. 화면 구성 둘러보기](00_screens_readme.md) · 다음: [2. 새 PC 에서 시작하기](02_setup_readme.md)

| 영역 | 상태 | 비고 |
|------|------|------|
| 실행 구조 | 완료 | Spring Boot 실행형 war, 내장 PostgreSQL(로컬) / 외부 PostgreSQL(운영) |
| 로그인·로그아웃 | 완료 | Spring Security, CSRF, DB 기반 URL 권한 |
| 업무사용자(직원) 관리 | 완료 | 관리자 전용 |
| 권한 지정 | 완료 | 관리자 전용, `@RequireAdmin` + URL 규칙 이중 방어 |
| 표준프레임워크 규칙 자동 검증 | 완료 | `mvn package` 때 테스트로 확인 |
| 공지 게시판(게시판+게시물만) | 완료 | 관리자만 게시판 설정, 로그인한 누구나 글쓰기. [6. 공통컴포넌트 도입 현황과 설계](06_components_readme.md) |
| 일정관리(9개 모듈), 쪽지·주소록, 메일 발송, 메인 화면, 메신저(1:1), 메일 수신(IMAP) | 완료 | [7. 로드맵](07_roadmap_readme.md) |
| 운영 준비(CI, 세션 쿠키, 로그 파일) | 일부 완료 | HTTPS 리버스 프록시, DB 백업, 회원가입 화면은 아직 |
| 메신저(실시간), 메일 수신 | 예정 | 공통컴포넌트에 없어 직접 개발 |
| 메인 화면(대시보드) | 예정 | 지금 `/main.do` 는 DB 연결 확인용 임시 화면 |

- 자동 테스트 30개가 모두 통과합니다(`mvn clean package`).
- 브라우저로 로그인부터 전체 메뉴 클릭, 등록/저장까지 직접 점검을 완료했습니다([9. 겪었던 문제 모음](09_issues_readme.md) 참고). 새 PC 에서는 그래도 한 번 더 [화면 확인 체크리스트](02_setup_readme.md#화면-확인-체크리스트)를 해 주세요.
- 이 프로젝트는 AI 어시스턴트(Claude)와 함께 만들었고, 그 과정의 판단과 함정을 이 문서에 정리했습니다.
